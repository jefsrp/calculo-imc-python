# Calculadora de IMC em Python

Projeto desenvolvido em Python para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário.

## 📌 Sobre o projeto

Este é um projeto desenvolvido durante meus estudos de Python com o objetivo de praticar:

- Entrada de dados com `input()`
- Conversão de dados com `float()`
- Operações matemáticas
- Estruturas condicionais `if`, `elif` e `else`
- Uso de `f-strings`
- Organização de um projeto simples em Python

## 🚀 Como executar

1. Tenha o Python instalado no computador.
2. Abra o projeto no VS Code.
3. Abra o terminal.
4. Execute:

```bash
python imc.py
